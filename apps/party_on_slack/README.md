# Party on Slack のテスト項目

## 1. 初期セットアップとアクセス制御

### 1.1 アプリのインストール

1. https://lne.st/pt にアクセスする
2. Add to Slackボタンを押す
3. どのワークスペースにインストールするか選択する
4. 権限の確認をしてから許可ボタンを押す

https://youtu.be/ODa18XV4qj4

### 1.2 グローバルロック設定機能

1. ホーム画面を開く
2. 「ロックする」ボタンをクリックする
3. ロック対象の設定項目を選択する
4. 「ロック」ボタンをクリックする
5. 他のユーザーが設定を変更できないことを確認する

https://youtu.be/pyEUES06y4U

### 1.3 ワークスペース許可設定

1. ホーム画面を開く
2. 「ワークスペース許可」セクションの「開く」ボタンをクリックする
3. DMでの利用・マルチモーダル・画像生成・音声生成の許可設定を確認する
4. 必要に応じて「許可する」または「許可しない」を選択する

https://youtu.be/w-g0ItPHAaE

## 2. APIキー設定と基本認証

### 2.1 各種APIキーの登録・検証

#### API key 登録・検証

1. ホーム画面を開く
2. 「API key 設定」セクションの「設定」ボタンをクリックする
3. 登録したいAPIキーを入力欄に入力する
4. 「保存」ボタンをクリックする
5. 「API Keyは登録済みです」と表示されることを確認する

https://youtu.be/8oZmn4Hrh2k

### 2.2 使用モデル選択機能

1. ホーム画面を開く
2. 「使用モデル選択」セクションの「設定」ボタンをクリックする
3. 使用したいモデルにチェックを入れる
4. 「保存」ボタンをクリックする
5. チャンネルでモデル選択時に、選択したモデルのみが表示されることを確認する

https://youtu.be/dgqPeUedz7E

### 2.3 ワークスペースモデル設定

1. ホーム画面を開く
2. "チャット利用時に使用する言語モデルを選んで下さい"のドロップダウンからモデルを選択する
3. チャンネルでモデル選択時に、選択したモデルのみが表示されることを確認する

ワークスペースで登録したモデルよりチャンネルで選択したモデルが優先されます。

https://youtu.be/Gc9bOSykWcg

## 3. 基本的なAIチャット機能

### 3.1 チャンネルでのメンション応答

1. Party on Slackが参加しているチャンネルを開く
2. @Party on Slack をメンションしてメッセージを入力する
3. 送信する
4. AIからの返信がスレッドに表示されることを確認する
5. スレッドメニューが表示されることを確認する

https://youtu.be/2zJXFrQ2fss

### 3.2 DMでの会話

1. 左サイドバーから「Party on Slack」アプリを選択する
2. 「新しいチャット」をクリックする
3. メッセージを入力して送信する（メンション不要）
4. AIからの返信が表示されることを確認する

https://youtu.be/3zqQgsPuywo

### 3.3 スレッド内での継続的な会話

1. 既存のAIとの会話スレッドを開く
2. 新しいメッセージを入力して送信する
3. AIが前の会話の文脈を理解して返信することを確認する
4. 複数回やり取りを続けて、会話が継続することを確認する

https://youtu.be/N66LbMk-iXE

### 3.4 スレッドモデル変更機能

1. AIとの会話スレッドを開く
2. スレッドメニューの一番下にあるモデル選択ドロップダウンをクリックする
3. 使用したいモデルを選択する
4. 新しいメッセージを送信し、選択したモデルで返信が来ることを確認する

https://youtu.be/5aU89c2bzi8

### 3.5 チャンネルモデル変更機能

1. チャンネルでParty on Slackをメンションする
2. スレッドメニューのチャンネル設定ボタンをクリックする
3. モデル選択ドロップダウンからモデルを選択する
4. 設定するボタンをクリックする
5. 新しいメッセージを送信し、選択したモデルで返信が来ることを確認する

https://youtu.be/aPZzMGaErSI

### 3.6 キャラクター設定（システムプロンプト）

1. チャンネルでParty on Slackをメンションする
2. スレッドメニューのチャンネル設定ボタンをクリックする
3. キャラクター設定ボタンをクリックする
4. キャラクター設定テキストエリアにキャラクター設定を入力する
5. 設定するボタンをクリックする
6. 新しいメッセージを送信し、キャラクター設定が反映された返信が来ることを確認する

https://youtu.be/YFY-Ne_u_jg

### 4.1 ファイル要約（Word、PPT、Excel、CSV）

5. 「要約する」ボタンをクリックする
6. ファイルの要約がスレッドに投稿されることを確認する

https://youtu.be/MF5tZ4dq3SQ

### 4.2 URL要約

1. チャンネルでParty on Slackをメンションする
2. URLを含むメッセージを送信する
3. 「URLを無視する」「要約する」「質問する」ボタンが表示されることを確認する
4. 「要約する」ボタンをクリックする
5. URLの内容の要約がスレッドに投稿されることを確認する

https://youtu.be/uKNJtmmFlmI

### 4.3 画像認識（マルチモーダル）

5. 送信する
6. AIが画像を認識して適切な返答をすることを確認する

https://youtu.be/YN8XrjpyJdc

### 4.4 音声ファイルの文字起こし

1. チャンネルでParty on Slackをメンションする
2. 音声ファイルを添付する
3. 送信する
4. 「文字起こしする」「文字起こしして要約する」「文字起こしして質問する」ボタンが表示されることを確認する
5. 「文字起こしする」ボタンをクリックする
6. 音声の文字起こし結果がスレッドに投稿されることを確認する

https://youtu.be/Cth7xbC0EmE

## 6. 検索・統合機能

### 6.1 Web検索機能

1. Party on Slackをメンションする
2. スレッドメニューのWeb検索ボタンを"使用する"にする
3. ルーペアイコンが付いているモデルを選択する
4. 最新情報を必要とする質問をする
5. AIがWeb検索結果を含めた回答をすることを確認する

https://youtu.be/hdtz1iTUUss

### 6.2 Slackにきく機能（内部検索）

1. Party on Slackをメンションする
2. スレッドメニューのSlackにきくボタンをクリックする
3. ワークスペース内のメッセージに関する質問をする
4. AIがSlack内のメッセージを検索して回答することを確認する

https://youtu.be/nhVCi2Q8emg

### 6.3 Slackにきく機能（要約機能）

1. Party on Slackをメンションする
2. スレッドメニューのSlackにきくボタンをクリックする
3. 要約ボタンにチェックを入れる
4. 要約したいチャンネルや人物、期間を選択する
5. 送信する
6. 要約結果がスレッドに投稿されることを確認する

https://youtu.be/c8jFe3P9T9M

### 6.4 Pinecone連携（ベクトルDB）

1. アプリホーム画面でPinecone APIキーを設定する
2. 「Pineconeを利用する」ボタンを"使用する"にする
3. チャンネルで🍍スタンプを投稿に付ける
4. その投稿がPineconeに格納されることを確認する
5. その内容に関する質問をすると、格納された情報を参照して回答することを確認する

https://youtu.be/ggrNAy-g3W0

### 6.5 Google スプレッドシートRAG

1. アプリホーム画面でGoogle連携を許可する

3. Party on Slackをメンションする
4. スレッドメニューのチャンネル設定ボタンをクリックする
5. スプレッドシート検索する設定を"使用する"にする
6. スプレッドシートの内容に関する質問をして、適切に回答されることを確認する

この機能はOpenAIを利用してRAGを行っています。

## 7. 翻訳機能

https://youtu.be/QfKWcMJSD10

### 7.1 スタンプ翻訳設定

1. ホーム画面を開く
2. 翻訳機能セクションで「▶️スタンプ to 翻訳を利用する」ボタンをクリックする
3. 「🟢 国旗スタンプまたは🖋️を付けると、投稿内容が翻訳される設定になっています」と表示されることを確認する

DeepLのAPIキーまたはGoogle Cloud Service Account API Key, LLM ModelのAPIキー登録のいずれかが必要です。

### 7.2 翻訳モデル選択

1. ホーム画面の翻訳機能セクションを開く
2. 「使用する翻訳モデル」ドロップダウンから翻訳モデルを選択する（LLM Model、DeepL、Google翻訳）
3. 設定を保存する

登録した翻訳モデルが利用できます。
翻訳モデルがLLMモデルの場合、翻訳するモデルを選択できます。

### 7.3 翻訳先設定（スレッド/チャンネル）

1. ホーム画面の翻訳機能セクションを開く
2. 翻訳内容の投稿先設定で以下から選択する：
   - スレッドのみ
   - スレッドとチャンネル
   - チャンネルのみ
3. チャンネルで投稿に国旗スタンプ（🇯🇵、🇺🇸など）を付ける
4. 選択した投稿先に翻訳が表示されることを確認する

## 9. 外部サービス連携

### 9.1 Google連携（カレンダー調整）

2. Party on Slackをメンションする
