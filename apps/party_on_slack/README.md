# 主な機能

### AIチャット機能
- **マルチLLMプロバイダー対応**
  - OpenAI（GPT-3.5、GPT-4、GPT-4 Turbo）
  - Anthropic Claude
  - Amazon Bedrock（Stable Diffusion対応）
  - Google Gemini（Gemini-Pro、Gemini-Pro-Vision）
  - Azure OpenAI API対応
- **ファイル要約**（Word、PPT、Excel、CSV対応）
- **URL要約**（Web検索機能付き）
- **画像生成**（DALLE3、Stable Diffusion、Imagen）
- **音声生成**
- **マルチモーダル機能**（画像認識・分析）
- **音声文字起こし機能**

### 外部データソース連携
- **Pineconeベクトルデータベース連携**
  - 🍍スタンプでの自動ベクトル化
  - 自動格納機能（文字数設定可能）
- **Googleスプレッドシート RAG機能**
- **GoogleWorkspace連携**（Docs、スプレッドシート、スライド）
- **Web検索機能**（最新情報取得）
- **Slack検索機能**（ワークスペース内メッセージ検索）

### 外部サービス連携
- **RSSコンシェルジュ**（定期自動投稿）
- **Asana連携**
- **Salesforce連携**
- **Dify連携**（チャットボット、チャットフロー対応）

### 高度なSlack機能
- **スレッド要約機能**
- **返信案自動作成機能**
- **Canvas出力機能**（Slack有料プラン必要）
- **スタンプ翻訳**（DeepL、Google翻訳、LLM翻訳対応）

### OpenAI Assistant API機能
- **Assistant作成・管理機能**
- **Code Interpreter機能**（自律的思考・実行）
- **Retrieval機能**（ファイル添付での情報参照）

## セットアップ

1. ホーム画面を開きます
2. APIキー設定セクションの「設定」をクリックします
3. 任意の LLMプロバイダーのAPIキーを入力し、「保存」をクリックします
4. 以上より、適切なAPIキーがセットされていると「〇〇 APIキーは登録済みです」と表示されます
5. チャンネルにアプリを招待してください
6. 以上で、アプリが使用可能になります。

## AIチャット

1. チャンネルにてメンション、またはメンション+テキストを入力し、投稿してください
2. メッセージととともに、スレッドメニューが表示されます。
3. 続けてメッセージを投稿していくと、AIとの会話を続けることができます。

以上の機能は、DMでも使用可能です。

### モデル変更

- スレッドで使用したいモデルを変更したい場合は、モデル選択から、好きなモデルを選択してください。

### ファイル要約

1. チャンネルにてメンションとともにファイルを添付し、投稿してください
2. 「要約」ボタンをクリックします
3. 要約されたテキストがスレッドに投稿されます

### URL要約

1. チャンネルにてメンションとともにURLを入力し、投稿してください
2. 「要約」ボタンをクリックします
3. 要約されたテキストがスレッドに投稿されます

### 画像生成

1. スレッドメニューの「画像生成」をクリックします
2. テキストを入力し、「生成」をクリックします
3. 生成された画像ファイルがスレッドに投稿されます

### 音声生成

1. スレッドメニューの「音声生成」をクリックします
2. テキストを入力し、「生成」をクリックします
3. 生成された音声ファイルがスレッドに投稿されます

### RSSコンシェルジュ

1. スレッドメニューの「チャンネル設定」 をクリックしてください
2. チャンネル設定モーダルが表示され、その中の「RSSコンシェルジュ」をクリックしてください
3. 「登録」ボタンをクリックしてください
4. 登録したいRSSのURLを入力し、「登録」ボタンをクリックしてください
5. 登録したRSSに更新があれば、1hに1回、チャンネルに更新内容がLLMで処理された内容が投稿されます

## スタンプ翻訳

1. ホーム画面を開きします
2. 翻訳機能セクションより、「🟢 国旗スタンプまたは🖋️を付けると、投稿内容が翻訳される設定になっています」と表示されていることを確認してください
   1. もし、「🔴国旗スタンプを付けても投稿内容がDeepL翻訳されません。他のアプリで同様の処理をしている場合はこのままの設定で構いません。」と表示されている場合は、左に表示される「▶️スタンプ to 翻訳を利用する」ボタンをクリックし、有効にしてください。
3. 使用する翻訳モデルを選択してください。この機能は、任意のLLMモデル、 DeepL、またはGoole翻訳のいずれかが利用できます。
4. 以上で、スタンプ翻訳が利用可能になります。
5. アプリが参加しているチャンネルにて「🇯🇵」「🇺🇸」など、翻訳したい投稿に対してスタンプをつけると、投稿内容が翻訳されます。
